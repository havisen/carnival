        Overview

        Carnival turns a rough idea into a production-ready, photorealistic story. It uses DeepSeek for text generation, an image model (Seedream 5.0 Pro) for scene images, and your own API keys — which are encrypted at rest on the server and never sent back to the browser.

        The app is organized into tabs that follow a natural pipeline:

        1. Idea Generator — brainstorm concepts from a context.
        2. Project Management — organize ideas into projects and move them through stages.
        3. Reference Stage — generate detailed reference material, scene outline, and character references.
        4. Story Workspace — structure the brief, character bibles, locations, style, scenes, and character sheets.
        5. Generation Stage — write image prompts and generate scene images.
        6. Library — browse, review, and publish the images you produced.
        7. Settings — manage API keys, models, the Guide chat, and the Reviewer bot.

        Getting started

        1. Create an account and sign in.
        2. Open Settings and save a DeepSeek API key. This unlocks ideas, references, scene prompts, the Guide chat, and the Reviewer bot.
        3. To generate images, add a BytePlus key in Settings.
        4. Optionally add an Anthropic and/or OpenAI-compatible key to use other models for the Guide chat and Reviewer bot.

        Keys are stored encrypted (AES-256-GCM) on the server. The UI only ever shows a masked hint such as sk-…abc123.

        The workflow

        A project moves through three stages plus review:

        Idea Stage → Reference Stage → Generation Stage → Review/Complete
        • Idea Stage: the project holds the raw concept.
        • Reference Stage: generate and save reference material (this also fills the Story Workspace with reviewable drafts).
        • Generation Stage: generate prompts and images per scene.
        • Done: mark a project complete when it is finished; completed projects stay in the Library.

        The left sidebar's Workflow checklist shows, for the selected project, which steps are already finished.

        Idea Generator

        Context

        Paste background text, topic, constraints, or notes into the Context box — or drop a .txt file. The context is saved on your device and stays until you clear it with ✕ Clear context.

        Generating ideas

        1. Pick a model and the number of ideas.
        2. Click ✨ Generate ideas.
        3. Tick the ideas you want, then either ⬇ Export as .txt or ➜ Send to Project Management.

        Sending ideas to Project Management creates one project per selected idea in Idea Stage.

        Project Management

        Projects are grouped by stage. Each project card lets you:

        • ✎ Edit — change the title, idea, description, stage, status, priority, or reference material.
        • → Generation — move a Reference Stage project forward (requires saved reference material).
        • ✓ Complete / ↩ Reopen — mark a project done or bring it back.
        • Episodes — group a project's assets into episodes.
        • 🗑 Delete — remove the project (assets are archived, not destroyed).

        Use the search box and the status filter to find projects, and ⬇ Export to save a text snapshot.

        Reference Stage

        1. Choose a Reference Stage project.
        2. Add between 1 and 4 characters (name + gender) and an optional setting.
        3. Click ✨ Generate reference material.

        Use Use guide under the Setting field to ask the Guide for a setting suggestion for the current reference project. The Guide opens automatically with the prompt filled in.

        DeepSeek returns human-readable reference material (7 numbered sections), a chronological scene outline, standalone character references, and a structured Story Workspace payload.

        Nothing is auto-approved. The structured drafts (brief, characters, locations, style, scenes) are created as drafts awaiting review. Regenerating will ask you to confirm before it replaces existing records.

        You can edit the reference text and click 💾 Save reference, or ↻ Regenerate to try again.

        Story Workspace

        The Story Workspace is the canonical, structured root of the story. It is built from reference generation and fully editable by hand.

        Story brief

        Title, logline, premise, tone, genre, audience, and setting summary. Edit and Save brief.

        Character bibles

        Each character has name, gender, age, appearance, wardrobe, and continuity notes, plus any legacy reference material. Click ✓ Approve to mark a character canonical.

        Locations

        Each location has a description, lighting, and continuity notes. Approve locations the same way.

        Style references

        A visual style with description, guidance, and negative exclusions. Approve to mark it canonical.

        Scene matrix

        Each scene has a title, beat, props, action, and links to a location and characters. Only approved locations/characters can be linked for scenes you save manually.

        Character sheets

        Pick a character and ✨ Generate character sheet to produce a photorealistic reference image (full-body, canonical wardrobe and appearance) from their bible and style. Each generation creates a new version; promote one to final.

        Approval

        Generated records start unapproved. Approve character, location, and style references explicitly. Check continuity reports genuine missing information and pending approvals — it never approves anything by itself.

        Generation Stage

        1. Choose a Generation Stage project (it must already have reference material).
        2. Review the scene list, then click Generate prompts to write one photorealistic image prompt per scene.
        3. Edit or Regenerate individual prompts as needed.
        4. Choose an image size and click Generate image for each scene.

        You can also upload your own PNG/JPEG/WebP image for a scene. Generated and uploaded images are stored in the Library.

        Review & Library

        The Library lists every image the app has produced or you have uploaded, with filtering by project, episode, collection, tag, type, and status.

        Reviewing an image

        • Record a review decision: REVISE, REJECT, OWNER REVIEW, or APPROVED.
        • Complete the checklist (rights, adult-character, consent, explicitness, AI-label, placement, quality).
        • Choose a safe cover revision if needed.
        • Record a publication decision only when the evidence is complete.

        Approval and publication are separate, explicit human actions. A new revision invalidates prior review evidence.

        Sidebar, Guide & Reviewer

        Workflow checklist

        The Guide view shows a fixed checklist (Idea → Reference → Story brief → Characters → Locations → Style → Scenes → Prompts → Images → Completed) for the selected project.

        Guide

        Guide is a persistent chat that walks you through the workflow and suggests the next concrete action.

        Reviewer

        Reviewer is a field-by-field review bot. Choose a project and a section (for example Scene Prompts), then click Review. It checks every field in that section against the project context.

        • Purple ring — the field is processing.
        • Green check — the field was reviewed without blocking issues.
        • Red X — the field failed review or the check could not complete.

        Click Details to open a pop-up with each field's summary, findings, suggestions, model, and review time. Review results are an automated check — they are not a human approval or publication decision. Results are cached per field, so unchanged content is not re-reviewed.

        Change the provider, model, and extra instructions for the Guide chat and Reviewer bot in Settings → Chat assistants.

        Settings

        • DeepSeek API — key for ideas, references, scene prompts, and the default chat.
        • BytePlus image API — key for Seedream image generation.
        • Anthropic API — key for Claude models in the chat.
        • OpenAI-compatible API — key and base URL for any OpenAI-compatible provider.
        • Default models — the text and image models used across the app.
        • Chat assistants — per-assistant provider, model, and pasted context for the Guide chat and Reviewer bot.

        AI safety & approval

        Carnival keeps a hard boundary between generation and approval:

        • AI generates drafts; it never marks anything approved, final, or published.
        • Reference, Story Workspace, prompt, and image approvals are always explicit human actions.
        • Continuity warnings reflect genuine missing information or pending approvals — not information lost during import.
        • Regenerating never silently overwrites your edits or approvals; it asks for confirmation first.

        FAQ & troubleshooting

        “No API key is saved for your account”
        Add the corresponding key in Settings (DeepSeek, Anthropic, or OpenAI-compatible, depending on the assistant/model you are using).
        “Your API key was rejected (401)”
        The key is invalid or revoked. Update it in Settings.
        “Rate limit reached (429)”
        Too many requests. Wait a moment and try again.
        “Insufficient balance (402)”
        The provider account has no remaining balance.
        “Generate and save reference material first”
        A project must have reference material before it can enter Generation Stage.
        “Structured Story Workspace drafts already exist”
        Regenerating would replace existing records; confirm the replacement to continue.
        “A scene links to a character/location that is not approved”
        Approve the referenced character or location in Story Workspace before saving that scene link.
